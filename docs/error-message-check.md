## 🔧 修复内容

### 问题
之前 `getErrorMessage` 函数只检查 `response.data.message`，但后端实际返回的是 `response.data.error` 字段。

### 修复
更新 `src/utils/error.ts`：

```typescript
// 修复前
return err.response?.data?.message || '操作失败';

// 修复后
return err.response?.data?.error || err.response?.data?.message || '操作失败';
```

## 📝 错误提示规范

### ✅ 好的错误提示（当前实现）

1. **具体明确** - "邮箱已被注册" vs "注册失败"
2. **用户友好** - "邮箱或密码错误"（不透露用户是否存在）
3. **简洁明了** - 直接说明问题，没有冗余信息

### 🎯 安全考虑

登录失败时统一提示"邮箱或密码错误"是正确的安全实践，可以防止：
- 用户枚举攻击
- 暴露哪些邮箱已注册
