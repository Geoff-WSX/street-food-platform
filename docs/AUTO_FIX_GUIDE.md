## 📋 系统组件

### 1. Bug 排查技能 (bug-detection)

**文件**: `~/.claude/skills/bug-detection.md`

**功能**:
- 全面扫描前端、后端代码
- 识别 Bug、性能问题、代码质量问题
- 生成详细的排查报告

**触发**:
- 自动：每 60 秒
- 手动：`使用 bug-detection 技能进行全面排查`

### 2. Bug 分析技能 (bug-analysis)

**文件**: `~/.claude/skills/bug-analysis.md`

**功能**:
- 分析排查报告
- 评估问题影响范围和严重程度
- 计算优先级分数
- 生成分析报告

**评分标准**:
```
优先级分数 = 严重程度 × 30% + 影响范围 × 25% +
             修复价值 × 25% + (6 - 修复难度) × 20%
```

### 3. 修复方案规划技能 (bug-fix-planner)

**文件**: `~/.claude/skills/bug-fix-planner.md`

**功能**:
- 基于分析报告制定详细修复方案
- 分解任务为可执行步骤
- 规划时间安排
- 制定验证计划

**输出**: 完整的执行计划

### 4. Bug 修复执行 Agent (bug-fix-agent)

**文件**: `~/.claude/skills/bug-fix-agent.md`

**功能**:
- 按照方案执行代码修改
- 自动化修复常见问题
- 运行测试验证
- 提交代码并记录

**修复模式**:
- 简单替换
- 类型修复
- 依赖修复
- 错误处理添加

### 5. Bug 修复验证技能 (bug-verification)

**文件**: `~/.claude/skills/bug-verification.md`

**功能**:
- 验证修复是否成功
- 检查是否有新问题
- 评估代码质量提升
- 生成验证报告

**验证维度**:
- 问题解决
- 功能正常
- 无新问题
- 代码质量
- 性能影响
- 安全合规

## 🔄 自动化循环

### 循环流程

```
每 60 秒循环一次：

1. 检查项目服务状态
   ↓
2. 运行 Bug 排查
   ↓
3. 分析问题并计算优先级
   ↓
4. 如果发现 P0/P1 问题：
   - 规划修复方案
   - 执行自动修复
   - 验证修复结果
   ↓
5. 记录统计信息
   ↓
6. 等待 60 秒
   ↓
7. 返回步骤 1
```

### 停止条件

系统在以下情况下停止：

1. **手动停止**: 运行 `./scripts/stop.sh`
2. **服务停止**: 检测到前后端服务都停止
3. **用户中断**: Ctrl+C 信号
