技能名称：技能使用报告
简要描述
在每次用户命令执行完成后，自动分析并报告本次对话中调用了哪些技能（包括内置技能与自定义技能），说明每个技能被调用的具体位置、原因以及执行效果。若未使用任何技能，也明确告知用户。

使用场景
场景 1：调试与审计
开发者希望了解 AI 在执行命令时实际调用了哪些技能，检查技能是否按预期触发，避免遗漏或误用。

场景 2：教学与培训
新手用户或团队成员通过查看技能报告，学习在何种情况下应使用哪些技能，理解 AI 的决策逻辑。

指令
在每次完成用户命令所要求的全部操作后（包括但不限于文件增删改查、代码生成、测试执行等），必须执行以下步骤：

回顾本次对话上下文
从用户的最新一条消息开始，向前回溯 AI 的所有响应、工具调用及技能触发记录，识别所有被调用的技能。

提取技能信息
对于每个被调用的技能，记录：

技能名称：准确名称（如 edit_file、run_tests、search_code 等）。

调用位置：在对话中的哪一条消息或哪一个操作步骤中触发（例如：用户第 2 轮消息、AI 执行文件修改时）。

调用原因：该技能解决了用户的什么具体需求或实现了哪项操作（例如：用户要求“修复语法错误”，因此调用 edit_file 技能修改代码；用户要求“查找函数定义”，因此调用 search_code 技能）。

对“增删改查”的贡献：简要说明该技能是否进行了创建、删除、修改或查询操作。

生成报告
以清晰的格式输出报告，包含：

本次使用技能总数（若为 0，则直接说明未使用任何技能）。

技能清单：按调用顺序或重要性列出每个技能的上述信息。

未使用技能时的说明：如果未使用任何技能，解释主要原因（例如：仅进行了纯文本对话，未涉及文件操作或复杂分析）。

报告放置位置
将报告附加在本次命令的最终输出末尾，与主要回答内容之间用分隔线（如 --- 或 === 技能使用报告 ===）隔开。

特殊要求

若同一个技能被多次调用，需分别列出每次调用的位置和原因。

不得因生成报告而改变原有的命令执行结果或输出格式。

报告内容应简洁、准确，避免额外推断。

示例
用户命令：

查找项目中所有包含 TODO 的 Python 文件，并在每个文件末尾添加一行注释 # Reviewed: 2026-04-05。

AI 执行（隐式调用多个技能）后输出：

python
# 已找到 3 个包含 TODO 的 Python 文件：main.py, utils.py, config.py
# 已为每个文件末尾添加注释 # Reviewed: 2026-04-05
# 修改完成。

=== 技能使用报告 ===
本次命令共使用 2 个技能：

1. 技能名称：search_content  
   - 调用位置：执行用户命令的第一步，搜索 `TODO` 关键字时。  
   - 调用原因：定位所有包含 “TODO” 的 Python 文件，以满足用户查找要求。  
   - 增删改查：查询操作。

2. 技能名称：edit_file  
   - 调用位置：找到文件后，依次对 main.py, utils.py, config.py 执行修改时。  
   - 调用原因：在每个文件末尾追加注释行，完成用户要求的“添加注释”操作。  
   - 增删改查：修改操作（在现有文件中增加内容）。
用户命令（未触发任何技能）：

你好，你能做什么？

AI 输出：

text
你好！我可以帮助你进行代码编写、文件操作、测试运行等任务。请提出具体需求。

=== 技能使用报告 ===
本次命令未使用任何技能。原因：用户仅进行了一般性问候，未触发需要技能支持的操作（如文件读写、代码分析等）。
