# 违规判断技能

## 违规行为判定标准

### 垃圾信息 (Spam)

**认定标准：**
- 发布与平台主题无关的广告
- 重复发布相同或高度相似的内容
- 使用机器批量发送消息

**典型场景：**
```
✅ 违规：连续发布10条相同的商家广告
✅ 违规：私信推销代购服务
❌ 不违规：分享真实的用餐体验（即使多次）
❌ 不违规：推荐自己喜欢的店铺（非商业利益）
```

### 骚扰行为 (Harassment)

**认定标准：**
- 持续发送对方不欢迎的消息
- 使用侮辱性语言攻击他人
- 威胁、恐吓或恶意纠缠

**典型场景：**
```
✅ 违规：连续发送50条私信要求对方回复
✅ 违规：使用脏话辱骂其他用户
❌ 不违规：正常的意见分歧讨论
❌ 不违规：礼貌地询问商家信息
```

### 不当内容 (Inappropriate)

**认定标准：**
- 发布色情、暴力内容
- 发布违法信息（毒品、赌博等）
- 发布敏感政治内容

**典型场景：**
```
✅ 违规：发布赌博网站链接
✅ 违规：发布带有性暗示的图片
❌ 不违规：正常的美食图片
❌ 不违规：讨论社会新闻（非敏感内容）
```

### 虚假信息 (Fake)

**认定标准：**
- 伪造或篡改美食评价
- 发布虚假的地理位置信息
- 散布不实商家信息

**典型场景：**
```
✅ 违规：评价A店实际从未去过
✅ 违规：定位在虚假位置引流
❌ 不违规：主观感受不同（觉得不好吃）
❌ 不违规：地址信息有轻微误差
```

### 诈骗行为 (Scam)

**认定标准：**
- 索要钱财或敏感个人信息
- 发布虚假优惠活动
- 使用钓鱼链接窃取信息

**典型场景：**
```
✅ 违规：以"中奖"为由要求转账
✅ 违规：发送虚假优惠券链接
❌ 不违规：正常的优惠活动推广
❌ 不违规：正规的团购组织
```

## 边界情况处理

### 灰色地带判断

**情况1：用户争执**
- 单次争吵 → 不违规
- 互相辱骂 → 双方都违规
- 持续纠缠一方 → 骚扰违规

**情况2：商业推广**
- 明显广告 → 垃圾信息
- 个人推荐 → 不违规
- 商家正常发布 → 不违规

**情况3：内容真实性**
- 主观评价不同 → 不违规
- 明确虚假陈述 → 虚假信息
- 夸大宣传 → 视情况判定

## 从轻处理情节

以下情况可考虑从轻处理或警告：
1. **初犯** - 首次违规且情节较轻
2. **主动改正** - 在提醒后及时删除违规内容
3. **被挑衅** - 因对方挑衅而产生的反应
4. **误解** - 对规则理解有误

## 从重处理情节

以下情况应建议从重处罚：
1. **屡犯** - 多次违规且不改正
2. **恶意** - 明知故犯或故意违规
3. **影响恶劣** - 违规行为造成不良影响
4. **牟利** - 通过违规行为获取利益

## 处罚建议参考

| 违规程度 | 首次 | 再次 | 多次 |
|---------|-----|------|------|
| 轻微 | 警告 | 禁言1天 | 禁言3天 |
| 中等 | 禁言3天 | 禁言7天 | 封号 |
| 严重 | 禁言7天 | 封号 | 永久封号 |

---
**判断原则**：定性准确、量刑适当、教育为主
