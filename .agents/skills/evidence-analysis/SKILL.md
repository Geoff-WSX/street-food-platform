# 证据分析技能

## 图片证据分析

### 真实性检查
1. **查看图片完整性**
   - 是否有裁剪痕迹
   - 是否有编辑痕迹（马赛克、涂改）
   - 时间戳是否合理

2. **内容分析**
   - 图片内容是否与举报描述相符
   - 是否能清晰识别违规行为
   - 背景信息是否完整

### 常见伪造手段识别
- PS拼接图片
- 断章取义的截图
- 时间戳造假
- 冒充他人身份

## 聊天记录分析

### 上下文检查
1. **查看完整对话**
   - 不只是被举报的消息
   - 了解对话起因和过程
   - 判断双方的责任

2. **语气和意图**
   - 是否存在恶意攻击
   - 是否属于正常争执
   - 是否有挑衅行为

### 关键信息提取
- 违规言论的具体内容
- 发生时间和频率
- 涉及的用户数量

## 动态内容分析

### 内容合规性检查
1. **文字内容**
   - 是否包含违禁词
   - 是否存在虚假宣传
   - 是否有恶意引导

2. **图片内容**
   - 是否展示违规商品
   - 是否包含不当图像
   - 是否真实可信

### 商业行为判断
- 是否为明显的广告推广
- 是否涉及交易欺诈
- 价格和描述是否相符

## 用户行为模式分析

### 历史记录检查
- 用户过往的违规记录
- 举报次数和被举报次数
- 账号注册时间和活跃度

### 异常行为识别
- 短时间内大量发送相似内容
- 频繁更换账号信息
- 批量添加好友行为

## 综合判断方法

### 证据链完整性
```
举报描述 + 图片证据 + 聊天记录 + 用户历史 = 完整证据链
```

### 可信度评估
- 证据来源是否可靠
- 证据是否相互印证
- 是否存在明显矛盾

### 风险等级划分
| 等级 | 描述 | 建议处理 |
|-----|------|---------|
| 高风险 | 证据确凿，影响恶劣 | 立即处罚 |
| 中风险 | 证据较充分，需要警告 | 警告+观察 |
| 低风险 | 证据不足，可能误判 | 驳回/补证 |
| 无风险 | 正常使用行为 | 驳回举报 |

---
**分析原则**：证据为王，客观公正，避免主观臆断
