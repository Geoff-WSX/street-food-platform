# 审核回复模板

## 审核通过（确认违规）

### 模板1：明确违规
```
经审核，确认被举报用户存在违规行为：

【违规类型】垃圾信息
【具体证据】
1. 用户在30分钟内发布8条相同内容的商家推广
2. 内容包含明显的广告用语和联系方式
3. 评论区多条用户反馈类似问题

【违反规则】社区规则第3条：禁止发布垃圾广告信息

【处理建议】建议删除违规内容 + 禁言3天

【审核说明】该用户行为明显属于商业推广，且重复发布严重影响社区体验
```

### 模板2：骚扰行为
```
经审核，确认被举报用户存在骚扰行为：

【违规类型】骚扰
【具体证据】
1. 聊天记录显示用户连续发送20+条未获回应的消息
2. 包含"为什么不理我"、"回我"等纠缠性语言
3. 对方已明确表示不愿继续交流

【违反规则】社区规则第5条：禁止骚扰其他用户

【处理建议】建议警告 + 禁言7天

【审核说明】该行为已超出正常社交范畴，对他人造成困扰
```

### 模板3：虚假信息
```
经审核，确认被举报用户发布虚假信息：

【违规类型】虚假信息
【具体证据】
1. 用户评价店铺为"正宗老字号"，实际为新开业店铺
2. 定位显示的地址与实际不符
3. 配图与实际店铺环境不符

【违反规则】社区规则第4条：禁止发布虚假信息

【处理建议】建议删除虚假评价 + 警告

【审核说明】虚假信息误导其他用户，损害平台公信力
```

## 审核不通过（未发现违规）

### 模板1：证据不足
```
经审核，未发现被举报用户存在违规行为：

【审核结果】驳回举报

【原因说明】
1. 举报人提供的截图不完整，无法看到完整对话
2. 缺少关键的上下文信息
3. 证据的真实性无法核实

【补充建议】建议举报人补充完整聊天记录和时间戳

【审核说明】现有证据不足以证明违规，建议补证后重新举报
```

### 模板2：正常行为
```
经审核，被举报用户行为属于正常使用：

【审核结果】驳回举报

【原因说明】
1. 用户发布的内容为真实的用餐体验分享
2. 虽然多次提及同一商家，但属于个人推荐性质
3. 不存在明显的商业推广意图

【审核说明】该行为属于正常的社区互动，不构成违规
```

### 模板3：双方责任
```
经审核，举报情况较复杂，建议双方协商：

【审核结果】驳回举报

【原因说明】
1. 双方在讨论中产生分歧，属于正常观点差异
2. 虽然言辞激烈，但未达到辱骂程度
3. 双方均有情绪化表达

【处理建议】建议双方冷静沟通，平台将关注后续情况

【审核说明】此类纠纷建议私下协商解决，不构成单方违规
```

## 特殊情况模板

### 模板1：需要进一步调查
```
该举报情况较为复杂，需要进一步调查：

【当前情况】
1. 涉及多名用户
2. 时间跨度较大
3. 需要更多后台数据支持

【处理建议】
建议转交管理员进行深入调查，可能需要：
- 查看完整聊天记录
- 分析用户行为模式
- 核实账号真实性

【审核说明】当前证据不足以做出判断，建议暂缓处理
```

### 模板2：疑似恶意举报
```
经审核，发现可能存在恶意举报情况：

【疑点】
1. 举报人与被举报人存在私人纠纷
2. 举报内容明显断章取义
3. 证据有篡改痕迹

【处理建议】
建议驳回举报，并关注举报人是否存在滥用举报功能的情况

【审核说明】恶意举报浪费审核资源，建议对举报人进行警告
```

## 快速回复短语

### 确认违规
- "证据充分，确认违规"
- "违规行为明显，建议处罚"
- "多次违规，建议从重处理"
- "影响恶劣，建议立即处理"

### 驳回举报
- "证据不足，无法认定违规"
- "属于正常行为，不构成违规"
- "双方均有责任，建议私下协商"
- "举报理由不成立"

### 需要更多信息
- "证据不完整，建议补证"
- "需要更多上下文信息"
- "建议提供完整聊天记录"
- "时间戳信息缺失"

---
**使用提示**：根据具体情况选择合适的模板，并填写具体细节
