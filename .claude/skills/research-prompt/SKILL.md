# 网站研究与提示词生成技能

## 技能概述
在需求验证通过后，研究类似功能的实现方式，生成优化的实施提示词。

## 工作流程

### 第一步：需求分析
1. 核心功能点是什么？
2. 涉及哪些技术领域？
3. 有哪些关键约束条件？

### 第二步：网站研究
使用 WebSearch 搜索相关实现：

#### 搜索策略
```
1. 技术实现类: "[功能名] 实现 [技术栈]"
   例: "搜索框自动完成 React 实现"

2. 最佳实践类: "[功能名] 最佳实践"
   例: "搜索自动完成 最佳实践"

3. 开源方案类: "[功能名] 开源库"
   例: "pinyin search javascript library"

4. 竞品分析类: "[知名产品] [功能名] 实现"
   例: "淘宝搜索框 拼音 输入"
```

#### 研究重点
- 主流实现方案
- 常用库/工具
- 性能优化技巧
- 用户体验设计
- 常见问题及解决方案

### 第三步：综合分析
1. **技术选型**: 哪些方案适合当前项目？
2. **实现复杂度**: 需要多少工作量？
3. **风险评估**: 可能遇到什么问题？
4. **优化建议**: 有哪些可以改进的地方？

### 第四步：生成提示词
结合研究和需求，生成详细的实施提示词。

## 使用示例

### 示例1: 拼音搜索功能
**需求**: "用户输入拼音也能搜索中文内容"

**研究过程**:
```
搜索1: "pinyin search javascript library"
结果: 发现 pinyin-pro 库

搜索2: "搜索框 拼音 输入 最佳实践"
结果: 了解前缀匹配 vs 包含匹配的区别

搜索3: "autocomplete 拼音 React"
结果: AutoComplete 组件使用方式
```

**生成的提示词**:
```markdown
# 拼音搜索功能实施方案

## 技术选型
- 前端: Ant Design AutoComplete
- 后端: pinyin-pro 库
- 匹配策略: 前缀匹配（startsWith）

## 关键实现
### 后端
1. 安装 pinyin-pro
2. 创建拼音转换工具
3. 修改搜索接口支持拼音匹配

### 前端
1. 使用 AutoComplete 组件
2. 调用 /suggest API 获取建议
3. 展示下拉列表

## 注意事项
- 使用 startsWith 而非 includes，避免误匹配
- 缓存常用词汇的拼音，提升性能
- 支持完整拼音和首字母两种匹配方式
```

### 示例2: 图片懒加载
**需求**: "列表中的图片实现懒加载"

**研究过程**:
```
搜索1: "image lazy load React"
结果: 发现 react-lazy-load-image-component

搜索2: "IntersectionObserver 懒加载 最佳实践"
结果: 了解原生 API 使用方式
```

**生成的提示词**:
```markdown
# 图片懒加载实施方案

## 技术选型
- 方案: IntersectionObserver API（原生，无需额外库）

## 关键实现
### 创建 LazyImage 组件
1. 使用 IntersectionObserver 监听图片
2. 进入视口时加载图片
3. 加载失败显示占位符

### 集成到列表
1. 替换 img 标签为 LazyImage
2. 设置合理的 threshold

## 性能优化
- 设置 rootMargin 提前加载
- 使用 loading="lazy" 作为降级方案
```

## 配合使用

### 完整流程
```
用户提出需求
    ↓
调用 requirement-validation 技能
    ↓
验证通过 ✅
    ↓
调用 research-prompt 技能
    ↓
生成实施提示词
    ↓
按照提示词执行开发
```

### 技能调用示例
```
/skill 使用需求验证技能评估: "添加评论点赞功能"

/skill 使用研究技能为"评论点赞功能"生成实施方案
```
